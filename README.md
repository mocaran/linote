# linote 单机版

linote 是一款离线 Android 卡片笔记工具。打开应用即可创建本机档案，随手记录文字和图片，用 #话题 整理笔记，通过搜索和随机回顾找回过去的想法。笔记保存在当前设备。

灵感来自刘白光（Light），以及他与刘少楠合著的《笔记的方法》。linote 把书中用自己的话写卡片、用标签串联记录、定期回顾的做法融入日常记录。[《笔记的方法》](https://help.flomoapp.com/thinking/book.html)

适用于 Android 10 及以上。单机版可与联网版并存，使用独立的本机档案。当前版本暂不支持本机笔记导入和导出。
